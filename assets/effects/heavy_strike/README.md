# Heavy Strike effect

This editable impact adapts the CC0 `Sword1` sample by NextSoft01 from
Effekseer 1.80.7. It has longer arc/flash lifetimes and twelve longer-lived
sparks. `HeavyStrike.efkproj` is the editable source, and `HeavyStrike.efkefc`
is the Effekseer 1.80.7 output. The two texture images are from the same sample.
Attribution: Effekseer and NextSoft01 (sample license: CC0).

The guarded Effekseer emitter plays the effect on the committed Heavy Strike
impact frame. See https://effekseer.github.io/Helps/18x/Tool/en/ToolReference/index.html
for the effect format and command-line workflow.
