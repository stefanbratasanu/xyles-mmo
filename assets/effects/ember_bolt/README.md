# Ember Bolt effect

This projectile trail was adapted from the CC0 `MagicFire2` effect by NextSoft01, included in Effekseer 1.80.7. The adaptation reduces the particle count and adjusts its generation interval for the prototype. `EmberBolt.efkproj` is the editable source; `EmberBolt.efkefc` was generated with Effekseer 1.80.7 and is imported by the Effekseer Godot plugin. The flame texture is from the same sample.

To edit it, open `EmberBolt.efkproj` with `tools/Effekseer1.80.7Win/Tool/Effekseer.exe`, make changes, and save as `EmberBolt.efkefc` in this folder. Godot can then reimport it. The trail is attached to the pooled Ember Bolt projectile in `scripts/combat_effects.gd` and played in `scripts/main.gd`.
