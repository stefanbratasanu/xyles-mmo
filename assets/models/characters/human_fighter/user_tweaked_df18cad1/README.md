# User-tweaked Hyper3D fighter

Source model: `df18cad1-2a09-4c2f-9058-f4302348557b`; human rigging job: `9f8ddefd-f041-42bc-9ac7-37b72d4917a3`. `base.obj` and PNG maps are the original downloaded export; it has UVs but no material library binding its textures. `rigged_pbr.glb` is Hyper3D's rigged export with embedded PBR materials and textures; the playable player uses this copy. The rigged export has 63,990 vertices, 52 joints, no embedded animations, a 4096×4096 diffuse map, and 2048×2048 normal and metallic/roughness maps. Existing game animations retarget to the rig.

Inspect walking, sitting, hand grip and skin deformation in gameplay. The original OBJ and maps remain available for editing.
